# Java File I/O - Notes App

## Description

A console-based Notes App developed using Java. It allows users to create and view notes using file handling.

## Features

- Add new notes
- View saved notes
- Store notes in a text file
- Append notes without overwriting existing data
- Handle file I/O exceptions

## Technologies Used

- Java
- FileWriter
- FileReader
- BufferedReader
- Exception Handling

## How to Run

1. Compile the program using `javac NotesApp.java`.
2. Run the program using `java NotesApp`.

## Learning Outcomes

- Understanding Java File I/O
- Working with text files
- Handling exceptions using try-catch and try-with-resources
